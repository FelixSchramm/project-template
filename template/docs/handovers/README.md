# Handover archive

Snapshots of `HANDOVER.md`, written by the agent relay after every merged
issue PR, whenever the budget rule triggers, and at relay completion (see
`agents/RELAY.md`, section "Handover archive").

- File name: `YYYY-MM-DD_HHMM.md` (UTC timestamp of the snapshot).
- Content: the `HANDOVER.md` of that moment, prefixed with one line naming the
  timestamp and the reason.
- Append-only history: never edit or delete old snapshots.
